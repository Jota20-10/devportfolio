
# DevPortfolio

### Personal Portfolio | Portafolio Personal

A responsive, bilingual personal portfolio developed to showcase my technical skills, professional experience, and software projects.

Built with HTML, CSS, and vanilla JavaScript, using GitHub for version control and Netlify for continuous deployment.

## Live Demo

[Visit DevPortfolio](https://portfoliojeybinglm.netlify.app)

## About the Project

DevPortfolio is my personal website, designed to document my professional development and showcase projects in software development, information technology, and cloud computing.

### Key Features

- Spanish and English language support
- Language preference saved with localStorage
- Dynamic project cards
- Project filtering by category
- Professional experience timeline
- Technical skills organized by category
- Responsive layout for desktop and mobile
- Automatic deployment using GitHub and Netlify

## Running Locally

1. Clone the repository:

```bash
git clone https://github.com/Jota20-10/devportfolio.git
```

2. Open the project directory:

```bash
cd devportfolio
```

3. Open `index.html` in a web browser.

For development, you can also use the Live Server extension in Visual Studio Code.

No external dependencies are required.
